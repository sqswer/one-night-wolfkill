# 一夜狼人杀 · 在线版

基于《一夜狼人杀指南》全部角色与桌游流程，打造的一款**零依赖、可联机**的网页版 App。
创建房间 → 分享邀请 → 3-7 人组队 → AI 语音播报员按「黄昏 + 夜晚」顺序引导行动 → 白天语音/文字发言 → 投票 → 准确展示胜负。

## 快速开始

```bash
cd 一夜狼人杀在线网页版
node server.js
# 浏览器打开 http://localhost:3000
```

- 房主点「创建房间」，把**房间号 / 邀请链接**发给好友（手机同 Wi-Fi 访问 `http://<电脑局域网IP>:3000`）。
- 好友点「加入房间」输入房间号即可。
- 房主选阵容 →「开始游戏」。

> 无需 `npm install`，无需任何 API 密钥、无需联网即可游玩（语音为浏览器本地能力）。

## 部署到公网（户外手机也能玩）

> **2026-08 实测**：Koyeb（被收购无免费档）、Glitch（关停）、Render（要信用卡）、Hugging Face Spaces Docker/Gradio（需 PRO $9/月）——主流平台全部不可用。
>
> **当前确认免卡免费方案：Bonto / SnapDeploy**（小平台，见下方 `部署指南.md`）。代码零改动，`server.js` 已读 `process.env.PORT`。

### 快速部署：Bonto（推荐）

1. 注册 https://bonto.dev （免卡，Node.js 原生运行）。
2. Create New App → 上传 `server.js` + `package.json` + `public/` 全部文件。
3. Start Command 填 `node server.js` → Deploy。
4. 获得 `https://<app名>.bonto.run`，手机浏览器打开即可联机。

> 休眠 30 分钟（唤醒 ~2–5s），一局游戏 15–30 分钟在窗口内。详见 `部署指南.md`。

### 备选：自有服务器

```bash
git clone <你的仓库> && cd 一夜狼人杀在线网页版
node server.js
# 或 Docker：docker build -t oww . && docker run -d -p 3000:3000 oww
```

| 需求 | 实现 |
|---|---|
| 创建线上房间 | 房号制（6 位），房主可重开 |

## 角色能力覆盖

游戏内已内置**「角色图鉴」**（首页/大厅底部「📖 查看全部角色图鉴」），按阵营分组收录全部 **34 个角色**，每张卡展示：能力、胜利目标、玩法提示、行动阶段（夜晚/黄昏/白天/被动）。该图鉴数据来自 `public/roles.js`（`ROLE_LIB`），是展示层唯一数据源。

- **基础版**：狼人、爪牙、守夜人、预言家、强盗、捣蛋鬼、酒鬼、失眠者、村民、皮匠、猎人
- **破晓1/2**：哨兵、女巫、灵异侦探、见习预言家、村庄白痴、阿尔法狼、狼先知、化身幽灵、监护人、揭秘者、王子、被诅咒者、保镖、循迹者
- **吸血鬼扩展**：吸血鬼、伯爵、血奴（黄昏阶段）、牧师、神射手、小偷、小魔怪、丘比特、刺客（独立阵营，含「状态标记」子系统：吸血鬼/恐惧/清白/爱之/刺杀标记）

内置 15 套阵容预设（M1-M6 / A-E / V1-V5），与《指南》完全对应；V5 为三阵营「史诗战」（票死 ≥2 人结算）。

> 语音播报员已升级为完整**主持人口令**（`hint`），按官方 Announcer Script 口吻逐角色引导；胜负结算已修复官方「场上无狼」细则。详见《官方规则审计报告.md》。

## 技术架构（为什么难度最低）

- **后端**：Node.js 内置 `http`，用 **Server-Sent Events (SSE)** 做服务端→客户端实时推送，用 `fetch(POST)` 做客户端→服务端指令。**零第三方依赖**，不用安装任何包、不用数据库。
- **前端**：纯 HTML/CSS/JS，手机优先响应式。
- **语音**：全部使用浏览器内置 Web Speech API（播报员 TTS + 玩家语音识别），**免密钥、免联网、免费用**。

相比微信小程序（需开发者账号/云函数）或带 WebRTC 连麦的方案，此方案可在任意装了 Node 的机器上 `node server.js` 直接跑，跨设备用浏览器即可游玩，最快落地。

## 已知限制 / 后续可扩展

- **实时语音连麦（多人同时说话）**未做：当前白天「语音输入」是把玩家发言**转写成文字**广播，而非语音通话。若需真连麦，可加 WebRTC（难度较高）。
- 语音识别依赖浏览器支持（Chrome/Edge 体验最佳；Safari/Firefox 部分支持，可降级为纯文字）。
- 房间数据存内存，服务器重启即清空（适合聚会一局制；如需持久化可接 SQLite）。
- 化身幽灵/阿尔法狼等复杂机制做了**简化实现**（查看/交换），未完全复刻实体版全部细节。
- 暂无「机器人补位」与「跨服公网匹配」，邀请需同一局域网或内网穿透（如 ngrok/cloudflared）。
