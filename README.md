# 一夜狼人杀 · 在线版

基于《一夜狼人杀指南》全部角色与桌游流程，打造的一款**零依赖、可联机**的网页版 App。
创建房间 → 分享邀请 → 3-7 人组队 → AI 语音播报员按「黄昏 + 夜晚」顺序引导行动 → 白天语音/文字发言 → 投票 → 准确展示胜负。

## 部署到 Koyeb（免费公网）

本游戏是 **Node.js 后端 + 浏览器前端**：后端负责房间状态与实时同步，必须运行在一台"一直开机"的机器上。
Koyeb 提供**免费实例**（512MB 内存 / 0.1 vCPU / 2GB SSD），无需信用卡，适合个人聚会长期挂着。

> 本项目已内置 `Dockerfile` 和 `koyeb.yaml`，开箱即用。

### 第一步：注册 Koyeb 免费账号

1. 打开 [app.koyeb.com](https://app.koyeb.com)，点 **Sign up**。
2. 推荐直接点 **「Continue with GitHub」**——注册的同时就自动关联了 GitHub，跳到第二步即可。
3. 用邮箱 / Google / passkey 注册也行，同样**不要求填信用卡**。
4. 注册完即为免费档，无需任何付费操作。

> 如果注册时没关联 GitHub，后续可在 **右上角头像 → User settings → Link to GitHub** 补关联。

### 第二步：创建 Web Service

1. 登录 [app.koyeb.com](https://app.koyeb.com)，在控制台页面点 **「Create Web Service」**。
2. **Source** 选 **GitHub** → 授权 Koyeb 访问你的仓库（首次会跳转 GitHub 点 Authorize）。
3. **Repository** 选你存放本项目的仓库和分支。
4. **Builder** 选 **Dockerfile**（Koyeb 通常会自动检测到根目录的 Dockerfile）。
5. **实例规格**选 **Nano**（免费）。区域默认 Frankfurt 或 Washington D.C. 即可。
6. 点 **「Deploy」**，等待构建完成。

> 本项目根目录已有 `Dockerfile`（`node:20-alpine`，零依赖）和 `koyeb.yaml`（指定端口 3000、健康检查 `/api/presets`），无需额外配置。

### 第三步：开始游戏

部署完成后，你会获得一个 `https://xxx.koyeb.app` 的公网地址。手机浏览器打开即可创建 / 加入房间。

免费实例闲置时会自动休眠，下次访问冷启动几秒属正常。

### 要点

- 房间数据存内存，**重启即清空**，适合一局制聚会；如需持久化可自行接数据库。
- 手机端用 Chrome / Edge / Safari 打开公网链接，体验最佳（语音为浏览器内置能力）。
- 后续代码更新只需 `git push`，Koyeb 会自动重新构建部署。

## 已实现功能

| 需求 | 实现 |
|---|---|
| 创建线上房间 | 房号制（6 位），房主可重开 |
| 发送邀请 | 一键复制「房间号 + 邀请链接」 |
| 组队游玩 | 房间内玩家列表、准备状态，3-7 人 |
| AI 播报员（语音引导） | 服务端按固定顺序推送阶段口令，客户端用 **SpeechSynthesis** 中文 TTS 朗读「黄昏/夜晚/白天」全流程，可开关 |
| 黄昏 + 夜晚顺序行动 | 严格按指南夜行总顺序唤醒各角色；吸血鬼扩展含独立「黄昏」阶段（标记/恐惧/认亲） |
| 白天发言 + 语音实时输入 | **Web Speech API** 语音识别转写（Chrome/Edge 最佳），也支持文字输入 |

| 结果准确无误 | 服务端统一结算：狼队/好人/皮匠/猎人/王子顺延/保镖保护/吸血鬼多阵营，出局身份与胜负精确计算 |

## 角色能力覆盖

游戏内已内置**「角色图鉴」**（首页/大厅底部「📖 查看全部角色图鉴」），按阵营分组收录全部 **34 个角色**，每张卡展示：能力、胜利目标、玩法提示、行动阶段（夜晚/黄昏/白天/被动）。该图鉴数据来自 `public/roles.js`（`ROLE_LIB`），是展示层唯一数据源。

- **基础版**：狼人、爪牙、守夜人、预言家、强盗、捣蛋鬼、酒鬼、失眠者、村民、皮匠、猎人
- **破晓1/2**：哨兵、女巫、灵异侦探、见习预言家、村庄白痴、阿尔法狼、狼先知、化身幽灵、监护人、揭秘者、王子、被诅咒者、保镖、循迹者
- **吸血鬼扩展**：吸血鬼、伯爵、血奴（黄昏阶段）、牧师、神射手、小偷、小魔怪、丘比特、刺客（独立阵营，含「状态标记」子系统：吸血鬼/恐惧/清白/爱之/刺杀标记）

内置 15 套阵容预设（M1-M6 / A-E / V1-V5），与《指南》完全对应；V5 为三阵营「史诗战」（票死 ≥2 人结算）。

> 语音播报员已升级为完整**主持人口令**（`hint`），按官方 Announcer Script 口吻逐角色引导；胜负结算已修复官方「场上无狼」细则。详见《官方规则审计报告.md》。

## 技术架构（为什么难度最低）

- **后端**：Node.js 内置 `http`，用 **Server-Sent Events (SSE)** 做服务端→客户端实时推送，用 `fetch(POST)` 做客户端→服务端指令。**零第三方依赖**，不用安装任何包、不用数据库。
- **前端**：纯 HTML/CSS/JS，手机优先响应式。
- **语音**：全部使用浏览器内置 Web Speech API（播报员 TTS + 玩家语音识别），**免密钥、免联网、免费用**。

相比微信小程序（需开发者账号/云函数）或带 WebRTC 连麦的方案，此方案可在任意装了 Node 的机器上 `node server.js` 直接跑，跨设备用浏览器即可游玩，最快落地。

## 已知限制 / 后续可扩展

- **实时语音连麦（多人同时说话）**未做：当前白天「语音输入」是把玩家发言**转写成文字**广播，而非语音通话。若需真连麦，可加 WebRTC（难度较高）。
- 语音识别依赖浏览器支持（Chrome/Edge 体验最佳；Safari/Firefox 部分支持，可降级为纯文字）。
- 房间数据存内存，服务器重启即清空（适合聚会一局制；如需持久化可接 SQLite）。
- 化身幽灵/阿尔法狼等复杂机制做了**简化实现**（查看/交换），未完全复刻实体版全部细节。
- 暂无「机器人补位」与「跨服公网匹配」，邀请需同一局域网或内网穿透（如 ngrok/cloudflared）。
